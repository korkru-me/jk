# UAT ฟอร์ม IOC ระยะที่ 7

อัปเดตล่าสุด: 14 กันยายน 2569 (เพิ่มหมวดส่งออก Word หลังปล่อยรุ่น)

## สรุปสถานะ

**ส่วนเทคนิคผ่านทั้งหมด** บน branch `ioc-form-phase-0-spec` ทุกข้อในรายการข้างล่างตรวจด้วย dev server ที่ต่อฐานข้อมูล production จริง บัญชีครูจริง และข้อสอบจริงในคลัง ไม่ใช้ fixture ไม่ใช้ข้อมูลสมมติในฐานข้อมูล และข้อมูลทดสอบถูกลบทิ้งทุกครั้งเมื่อจบแต่ละรอบ

**ส่วนที่ต้องใช้คนจริงยังไม่ผ่าน** คณะผู้ทรงคุณวุฒิตัวจริงยังไม่เคยเปิดลิงก์จากอุปกรณ์ของตัวเอง และยังไม่มีใครสั่งพิมพ์เอกสารเป็น PDF ผ่านกล่องพิมพ์ของเบราว์เซอร์แล้วเอาไปยื่นจริง สองข้อนี้อยู่ในหัวข้อ "สิ่งที่ยังต้องรอของจริง" และเป็นเหตุผลที่รุ่นนี้ควรปล่อยแบบทดลองควบคุม ไม่ใช่ประกาศว่า UAT ผ่านครบ

## ขอบเขตและวิธีตรวจ

- ตรวจจาก `npm run dev` บนเครื่องพัฒนา ซึ่งชี้ไปยังฐานข้อมูล Supabase เดียวกับ production ไม่มีฐานข้อมูลในเครื่อง (โครงการนี้ไม่มี Docker ใช้งานอยู่)
- บัญชีที่ใช้เป็นบัญชีครู/แอดมินของเจ้าของผลิตภัณฑ์ องค์กรเป็น workspace ส่วนตัว
- หน้าผู้ทรงคุณวุฒิตรวจจากแท็บที่ไม่มี session และจาก `python urllib` ที่ไม่มี cookie เลย เพื่อไม่ให้ session ของครูช่วยให้ผ่านโดยบังเอิญ
- ข้อมูลทดสอบทุกชุดตั้งชื่อขึ้นต้นด้วย `UAT` และถูกลบเมื่อจบ · ไม่แตะข้อมูลนักเรียน คะแนน หรือห้องเรียนของจริงเลย เพราะโมดูลนี้ไม่อ่านข้อมูลเหล่านั้นอยู่แล้ว

## สิ่งที่ยังต้องรอของจริง

1. **คณะผู้ทรงคุณวุฒิตัวจริง** ยังไม่มีผู้ทรง 3 ท่านเปิดลิงก์จากเครื่องของตัวเอง กรอกจนส่ง และบอกว่าหน้าจออ่านเข้าใจไหม · ที่ตรวจแล้วคือการกรอกจนส่งได้จริงจากแท็บที่ไม่ล็อกอิน ซึ่งพิสูจน์กลไก แต่ไม่ได้พิสูจน์ความเข้าใจของคนใช้
2. **สั่งพิมพ์เป็น PDF จริง** เอกสารตรวจถึงระดับกล่องหน้ากระดาษ A4 บนหน้าจอ ความสูงของทุกหน้า และกฎ `@page` แล้ว แต่ยังไม่มีใครกดพิมพ์ผ่านกล่องพิมพ์ของเบราว์เซอร์แล้วเปิดไฟล์ PDF ที่ได้ (เครื่องมืออัตโนมัติเปิดกล่องพิมพ์ของระบบไม่ได้) · ควรเป็นข้อแรกที่เจ้าของผลิตภัณฑ์ลองเอง
3. **บัญชีครูคนที่สองและองค์กรที่สอง** ยังไม่ได้ยืนยันด้วยบัญชีจริงว่าครูต่างโรงเรียนเปิดฟอร์มของกันไม่ได้ · ที่ยืนยันแล้วคือ anon ถูกปฏิเสธที่ระดับ grant และ policy ทุกข้อผูกกับ `org_id`/`created_by` แต่การอ่านโค้ดไม่เท่ากับการลองด้วยบัญชีจริง
4. **มือถือจริง** ตรวจด้วยการจำลองขนาดจอเท่านั้น ยังไม่ได้ลองบนเครื่องจริงที่ผู้ทรงจะใช้
5. **ข้อสอบที่มีรูปภาพจำนวนมาก** ยังไม่ได้ทดสอบว่าการแบ่งหน้า A4 รับมือได้แค่ไหน ข้อสอบที่ใช้ตรวจเป็นข้อความล้วนและตาราง
6. **เปิดไฟล์ Word ในโปรแกรม Word จริง** ตรวจถึงระดับโครงสร้างไฟล์ (`.docx` คือ zip ของ XML และทุกส่วนที่ควรมีก็มี) แต่ยังไม่มีใครเปิดใน Word หรือ LibreOffice แล้วดูว่าหน้าตาออกมาอย่างไร โดยเฉพาะเมื่อเครื่องไม่มีฟอนต์ TH SarabunPSK
