# ADR 0001: ใช้ Brand line แบบ “ก่อ…โดยครู”

- สถานะ: Accepted
- วันที่: 18 สิงหาคม 2026
- ผู้ตัดสินใจ: เจ้าของผลิตภัณฑ์ KorKru

## บริบท

หน้า landing เดิมใช้ “ก่อการเรียนรู้ โดยครู” เป็นสโลแกนคงที่ แต่เจ้าของผลิตภัณฑ์ไม่ได้ตั้งใจให้คำว่า “การเรียนรู้” เป็นคำกลางเพียงคำเดียว

## การตัดสินใจ

ใช้ **“ก่อ…โดยครู”** เป็นระบบข้อความของแบรนด์ โดยรักษาคำว่า “ก่อ” และ “โดยครู” และเปลี่ยนคำตรงกลางตามบริบท เช่น การเรียนรู้ ข้อสอบ ห้องเรียน หรือการจัดการเรียนรู้

## เหตุผล

- สื่อว่าครูเป็นผู้สร้างและขับเคลื่อนการเรียนรู้
- ขยายไปกับฟีเจอร์ใหม่ได้โดยไม่เปลี่ยนแก่นแบรนด์
- เปิดพื้นที่ให้ครูตีความว่าเขากำลัง “ก่อ” อะไร

## ผลกระทบ

- ไม่ใช้ “ก่อการเรียนรู้ โดยครู” เป็นชื่อเต็มหรือสโลแกนถาวรโดยปริยาย
- UI ที่สลับคำต้องรองรับ reduced motion และไม่ทำให้ layout กระโดด
- คำกลางต้องสัมพันธ์กับหน้าหรือสิ่งที่ครูกำลังทำ
