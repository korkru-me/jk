# รายการทดสอบหน้าข้อสอบบน iPad จริง — เฟส 3B

สถานะ: **ยังไม่เริ่ม — รอผู้ใช้ว่าง**

ใช้เฉพาะหน้า `/exam-screen-lab` และข้อมูลจำลอง ห้ามใช้บัญชี คำตอบ รูป หรือไฟล์ของนักเรียนจริง Agent จะเปิด local URL และบอกผู้ใช้ทีละขั้นเมื่อผู้ใช้พร้อม

## ข้อมูลที่จดก่อนเริ่ม

- รุ่น iPad, รุ่น iPadOS และรุ่น Safari หรือ SEB
- มี Apple Pencil หรือไม่
- ใช้หนึ่งข้อต่อหน้าหรือสามข้อต่อหน้า

## รายการตรวจ

- เปิดแนวตั้งและแนวนอน แล้วหมุนกลับทั้งแบบหนึ่งและสามข้อต่อหน้า คำตอบต้องไม่หาย ไม่มีแถบขาวหรือการเลื่อนซ้าย–ขวา
- เปิด **ดูทุกข้อ**, เวลา, โหมดโฟกัส และกล่องยืนยันส่ง ปุ่มสำคัญต้องไม่ถูกขอบจอหรือคีย์บอร์ดบัง
- พิมพ์คำตอบไทยด้วยคีย์บอร์ดปกติ และคีย์บอร์ดลอยหรือแบ่งหากรุ่นรองรับ แล้วปิดคีย์บอร์ดได้
- จับคู่ทั้งแบบวางลงช่องและแบบโยงเส้นด้วยนิ้ว
- เรียงลำดับด้วยนิ้ว: ลากที่จุดจับได้ทันที; ลากจากตัวแถวต้องกดค้าง; เลื่อนหน้าผ่านบริเวณแถวได้ และปุ่มขึ้น/ลงยังทำงาน
- เปิดโจทย์ตารางจำแนกหลายมิติ แตะตัวเลือกให้ครบทุกแถว และตรวจว่าป้ายชื่อแถว/คอลัมน์ไม่หายทั้งสองแนวจอ
- หากมี Apple Pencil ให้ทำจับคู่ เรียงลำดับ และเขียนกระดาษทดซ้ำด้วย Pencil โดยเฉพาะตรวจว่าการเลื่อนหน้าและการลากไม่แย่งกัน
- เปิดเครื่องคิดเลขและแป้นคณิตศาสตร์ แตะทุกแถวของปุ่ม เลื่อนภายในแผงได้ และปิดแผงได้ทั้งสองแนวจอ
- เปิดกระดาษทด วาด ลบ เปลี่ยนขนาดเส้นและพื้นหลัง แล้วหมุนจอ งานในกระดาษทดต้องไม่หาย
- เปิด camera/file picker ด้วยไฟล์สมมติเท่านั้น ทดสอบทั้งการยกเลิกและการเลือกไฟล์ ตรวจว่าชื่อ/สถานะไฟล์แสดงถูกต้อง ลบไฟล์ออกได้ และกลับมาหน้าข้อสอบตำแหน่งเดิม
- เปิดกล่องยืนยันส่งแต่ไม่กดยืนยันส่งข้อมูลจริง ตรวจว่ากลับไปแก้คำตอบได้

## ข้อจำกัดของผลจำลอง

Chrome browser simulation ในเฟส 3A ไม่สามารถพิสูจน์ Safari/WebKit, safe area ของ iPadOS, คีย์บอร์ดลอย/แบ่ง, event จาก Apple Pencil, camera/file picker, การหมุนเครื่องจริง หรือพฤติกรรมใน SEB ได้ เฟส 3 จะผ่านเมื่อรายการข้างบนทดสอบบน iPad จริงครบและแก้ปัญหาที่ทำซ้ำได้แล้วเท่านั้น

บันทึกเฉพาะวันที่ รุ่นอุปกรณ์/OS/แอป แนวจอ กรณีที่ทดสอบ และอาการที่ไม่มีข้อมูลส่วนบุคคล ห้ามส่งหรือ commit password, CK/BEK, token, คำตอบจริง รูปลายมือจริง หรือไฟล์ข้อสอบจริง
