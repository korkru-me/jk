# รายการทดสอบหน้าข้อสอบบน iPad จริง — เฟส 3

อัปเดต: 20 กันยายน 2026 · **agent-only ผ่านแล้ว — physical-device UAT รอรวมหลังเฟส 8**

ใช้เฉพาะหน้า `/exam-screen-lab` และข้อมูลจำลอง ห้ามใช้บัญชี คำตอบ รูป หรือไฟล์ของนักเรียนจริง การตรวจในเบราว์เซอร์จำลองไม่ใช่หลักฐานแทน Safari, SEB, นิ้ว, Apple Pencil หรือคีย์บอร์ด iPad จริง

## ผล agent-only

- ตรวจ 512×1024 (Split View), 768×1024 (iPad มาตรฐาน), 1024×1366 และ 1366×1024 ทั้งสามข้อต่อหน้า ไม่พบ document overflow หรือ control หลุดซ้าย/ขวา
- iPad แนวตั้งและ Split View ซ่อน navigator ด้านขวาที่เคยบีบเนื้อหา แล้วใช้ปุ่ม **ดูทุกข้อ** เปิด dialog ที่มี touch target 44px, เวลา, สถานะทุกข้อ และปุ่มส่งแทน; iPad แนวนอน/จอกว้างยังใช้ navigator ด้านขวา
- dialog ดูทุกข้อและยืนยันส่งรองรับความสูง viewport จริง, safe-area, scroll ภายใน, Escape และ focus trap
- แป้นคณิตศาสตร์และเครื่องคิดเลขจำกัดความสูงด้วย `--app-height`/`100dvh`, เลื่อนภายในได้ และไม่หลุดจอใน Split View
- กระดาษทดเต็มจอจนถึง breakpoint `lg`; toolbar ไม่ถูกบีบเป็นแผงข้างบน iPad แนวตั้ง และปุ่มหลักเพิ่มขนาดสำหรับ pointer แบบ coarse
- จับคู่แบบช่อง, โยงเส้น และเรียงลำดับผ่านการกดจำลอง; จุดจับ/ปุ่มเลื่อนมี touch target เพิ่ม และแยก mouse ออกจาก touch/pen เพื่อให้ลากจาก handle ได้ทันที แต่ลากจากแถวต้องกดค้างเพื่อไม่แย่งการเลื่อนหน้า
- Next MCP รายงาน compilation/config/session issues ว่าง และ browser console ไม่มี runtime error
- axe WCAG A/AA พบเฉพาะ contrast ของลายน้ำโปร่งใสที่ตั้งใจเป็นสิ่งตกแต่งและถูก `aria-hidden`; ไม่พบ violation ของ control หรือเนื้อหาที่ผู้ใช้ต้องอ่าน
- `npm test` ผ่าน 96 files / 1,310 tests; TypeScript, design-token lint และ production build 63 static pages ผ่าน

## สิ่งที่ต้องทดสอบบน iPad จริงหลังเฟส 8

- จดรุ่น iPad, iPadOS, Safari/SEB และว่ามี Apple Pencil หรือไม่
- หมุนแนวตั้ง/แนวนอนและเข้า Split View ทั้งหนึ่งและสามข้อต่อหน้า ขณะเปิด/ปิดคีย์บอร์ดไทย
- เปิด **ดูทุกข้อ**, เวลา, โหมดโฟกัส และกล่องยืนยันส่ง ตรวจว่าปุ่มไม่ถูก safe-area หรือคีย์บอร์ดบัง
- จับคู่ทั้งสองแบบและเรียงลำดับด้วยนิ้ว; หากมี Pencil ให้ทำซ้ำและตรวจว่าการเลื่อนหน้าไม่ถูกการลากแย่ง
- เปิดเครื่องคิดเลข แป้นคณิตศาสตร์ และกระดาษทด วาด/ลบ/หมุนจอ แล้วตรวจว่างานไม่หาย
- ใช้ไฟล์สมมติทดสอบ camera/file picker ทั้งยกเลิก เลือก และลบไฟล์ โดยไม่ส่งข้อมูลจริง

ผล physical UAT วันที่ 21 กันยายน 2026: เมนู **ดูทุกข้อ** และจับคู่แบบช่องผ่าน
ส่วนจับคู่แบบลากเส้นพบว่าลากได้เฉพาะซ้ายไปขวาและต้องเล็งจุดวงกลมขนาดเล็ก จึงปรับ
ให้กดค้างแล้วลากจากพื้นที่การ์ดได้ทั้งซ้ายไปขวาและขวาไปซ้าย โดยยังสงวน gesture
