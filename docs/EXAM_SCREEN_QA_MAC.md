# รายการตรวจหน้าข้อสอบบน Mac จริง — เฟส 4B

อัปเดต: 12 กันยายน 2026 · **ยังไม่เริ่ม — รอผู้ใช้ว่าง**

เอกสารนี้เก็บขั้นตอนที่ต้องทำภายหลังเท่านั้น ผู้ใช้ยังไม่ต้องทดสอบตอนนี้ เฟส 4A ตรวจโค้ดและจำลองด้วย Chrome บนเครื่องพัฒนา แต่ผลนั้นไม่ใช่หลักฐานจาก Safari/WebKit หรือแอป SEB บน Mac จริง

## ก่อนเริ่มภายหลัง

- Agent จะเปิดห้องทดลอง local และบอกทีละขั้น ผู้ใช้ไม่ต้องจำ URL หรือเปิดหลายอย่างเอง
- ใช้ `/exam-screen-lab` และข้อมูลสมมติเท่านั้น ห้ามใช้บัญชี ชื่อนักเรียน คำตอบ รูปลายมือ หรือไฟล์ข้อสอบจริง
- จดเฉพาะรุ่น Mac/ชิป, รุ่น macOS, รุ่น Safari, ขนาดและ scaling ของจอ, มีจอนอกหรือไม่, อุปกรณ์ชี้ที่ใช้ และผล “ผ่าน/ไม่ผ่าน”
- ห้ามส่งหรือ commit password, CK, BEK, token, ticket, request hash หรือ URL ที่มี query ลับ
- ก่อนเริ่ม Agent ต้องยืนยันว่า route เป็น `/exam-screen-lab` และไม่เชื่อมการส่งคำตอบจริง

## ขั้นตอนที่ Agent จะบอกทีละข้อ

1. เปิดแบบหนึ่งข้อต่อหน้าใน Safari ย่อหน้าต่างให้เล็ก แล้วขยายเป็นเต็มจอ ตรวจว่าไม่มีการเลื่อนซ้าย–ขวา ข้อความทับกัน หรือปุ่มสำคัญหาย
2. เปิดแบบสามข้อต่อหน้า เลื่อนจากต้นถึงท้าย แล้วปรับขนาดหน้าต่างผ่านจุดที่แถบนำทางเปลี่ยนเป็นปุ่ม **ดูทุกข้อ** คำตอบที่กรอกไว้ต้องไม่หายระหว่างปรับขนาด
3. ใช้ Tab และ Shift+Tab เดินผ่านปุ่มและช่องตอบทั้งหมด ตรวจว่าเห็นกรอบ focus และไม่มีจุดที่คีย์บอร์ดติดออกไม่ได้ ใช้ Enter/Space กับปุ่ม ตัวเลือก และ checkbox ที่รองรับ
4. เปิด **ดูทุกข้อ** และกล่องยืนยันส่งด้วยคีย์บอร์ด ตรวจว่า focus อยู่ในกล่อง กด Escape แล้วปิดได้ และ focus กลับไปยังปุ่มที่ใช้เปิด
5. พิมพ์ข้อความไทยหลายบรรทัดและคำตอบคณิตศาสตร์ ใช้แป้นคณิตศาสตร์ใส่ค่าที่ตำแหน่ง cursor แล้วตรวจว่าการเลื่อนหน้าไม่กระโดด
6. ทำปรนัย ถูก–ผิด เติมคำ และตารางจำแนกด้วย keyboard/mouse ตรวจข้อความยาวและ label ทุกแถวที่ browser zoom 125%, 150% และ 200%
7. จับคู่ทั้งแบบวางลงช่องและโยงเส้นด้วย mouse/trackpad แล้วทำซ้ำด้วยทางเลือก keyboard เรียงลำดับด้วย drag แล้วทำซ้ำด้วยปุ่มขึ้น/ลง
8. เปิดเครื่องคิดเลข ประวัติการคำนวณ แป้นคณิตศาสตร์ และกระดาษทด ตรวจ scroll ภายใน ปุ่มปิด Escape และการกลับ focus โดยไม่บังปุ่มนำทางหรือปุ่มส่ง
9. บนกระดาษทดให้วาด ลบ เปลี่ยนพื้นหลัง ซูมด้วย trackpad แล้ว reset zoom ตรวจว่าไม่เกิดแถบขาวหรือพื้นที่วาดหาย การแนบใน lab ต้องแสดงว่าเป็นการจำลองและไม่อัปโหลด
10. เปิด file picker ด้วยไฟล์สมมติเท่านั้น ทดสอบทั้ง Cancel และเลือกรูป/PDF ตรวจชื่อ สถานะ ปุ่มนำออก และตำแหน่ง scroll/focus เมื่อกลับจาก picker
11. เปิดโหมดโฟกัส สลับข้อ เปิด overlay ขณะหน้าต่างเล็กและขณะ zoom แล้วกลับโหมดปกติ ตรวจว่าไม่มี action ที่เอื้อมไม่ถึง
12. เปิดกล่องยืนยันส่งและย้อนกลับไปแก้คำตอบ หากทดสอบหน้าผลลัพธ์ของ lab ให้ยืนยันว่ามีป้ายว่าเป็น preview และไม่มีข้อมูลถูกส่งจริง

## สิ่งที่ผลเฟส 4B ยังพิสูจน์ไม่ได้

- Chrome simulation ไม่พิสูจน์ Safari/WebKit, native file picker, trackpad gesture หรือพฤติกรรมจริงบน Mac
- Safari ผ่านไม่ได้แปลว่า SEB ผ่าน เพราะ SEB มี kiosk policy, URL filtering, JavaScript API และข้อจำกัดจากไฟล์ `.seb` เพิ่ม
- ห้องทดลองไม่พิสูจน์ login, autosave, reload/resume, upload, submit, RLS, ห้องคุมสอบ หรือ quit link เพราะ preview ตั้งใจไม่เก็บคำตอบข้าม reload
- การเลือกไฟล์หรือเปิดหน้าต่างใหม่ที่ถูกปฏิเสธใน SEB อาจมาจาก policy ในไฟล์ `.seb` ต้องแยกจาก layout bug ก่อนแก้โค้ด

## หลักฐานที่ต้องฝากไปทดสอบ SEB บน Mac ในเฟส 6

- ใช้ไฟล์ `.seb` ฉบับสุดท้ายกับ canonical HTTPS staging URL และ SEB build ที่จะประกาศรองรับจริง
- จดเฉพาะชื่อ/รุ่น config, รุ่น macOS และรุ่น SEB บันทึกเพียงว่า CK+BEK “ตรง/ไม่ตรง” ห้ามคัดลอกค่ากุญแจลงเอกสารหรือภาพ
- System check ต้องผ่าน JavaScript API, platform/version, exact CK+BEK และ signed SEB session ก่อนเริ่ม
- ต้องทดสอบเริ่มสอบ, autosave, เน็ตหลุดแล้ว resume, รูป/PDF, ส่งจริงใน staging, สถานะที่ครูเห็น และลิงก์ออกหลังส่ง การเปิด SEB ได้อย่างเดียวไม่ถือว่าผ่าน
- Quit link ต้องออกได้เฉพาะ flow ที่อนุญาต และ Quit Password เป็นทางกู้คืนที่เก็บนอกแชต/เอกสาร ห้ามจงใจทำให้ SEB ค้างหรือบังคับปิดเครื่องเพื่อทดสอบ
- ผลผูกกับ exact SEB build และ exact `.seb` file: อัปเดต SEB อาจเปลี่ยน BEK และบันทึกไฟล์ config ใหม่อาจเปลี่ยน CK จึงต้องเก็บ key ใหม่และทดสอบซ้ำ

เฟส 4 จะเปลี่ยนเป็น “ผ่าน” ได้เมื่อรายการ Safari บน Mac จริงครบและแก้ปัญหาที่ทำซ้ำได้แล้วเท่านั้น ส่วน SEB บน Mac ยังคงเป็น release gate ของเฟส 6 และห้ามเลื่อนสถานะตามผล Safari

บันทึกเฉพาะวันที่ รุ่นเครื่อง/OS/browser/app, จอและ scaling, ขนาดหน้าต่าง, input ที่ใช้, กรณีทดสอบ, ผ่าน/ไม่ผ่าน และขั้นตอนทำซ้ำที่ไม่มีข้อมูลส่วนบุคคล ภาพหลักฐานต้องครอป URL/query และข้อมูลลับออกก่อนเก็บ
