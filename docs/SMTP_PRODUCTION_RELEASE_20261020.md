### ทางเลือก link branding ที่ศึกษาจากเอกสารปัจจุบัน (ยังไม่ทำ)

[Supabase Email templates](https://supabase.com/docs/guides/auth/auth-email-templates#limitations) รองรับการปรับ subject/body และแนะนำปิด email tracking; เอกสารมีตัวอย่าง confirmation landing page ที่ต้องกดปุ่มเพื่อกัน scanner ใช้ token แต่ตัวอย่างไม่ใช่ drop-in recovery patch ของเรา `/auth/confirm` ปัจจุบันรองรับ signup/email และใช้ `verifyOtp` จึงห้ามสลับ recovery template ไป endpoint นี้เพื่อข้าม nonce/PKCE/recipient binding หากพัฒนา first-party gate ในอนาคต ต้องอยู่ใน cookie scope ที่เหมาะสม ตรวจ exact provider host/path/type และ nested callback/nonce, GET ห้าม consume/auto-redirect, ไม่มี arbitrary redirect/analytics/client serialization และตรวจ token exposure ใน edge/access logs ก่อน ไม่ copy wrapper query จากตัวอย่างโดยอ้างว่าไม่มีความเสี่ยง การเปลี่ยนนี้เป็น Auth scope แยกที่ยังไม่อยู่ใน candidate และยังไม่ได้ apply

[PKCE](https://supabase.com/docs/guides/auth/sessions/pkce-flow#limitations) ต้องใช้ verifier จากเบราว์เซอร์/อุปกรณ์ที่เริ่ม flow; คง callback intent/recipient/user/session checks และ ten-minute recovery grant เดิม [Supabase custom domain](https://supabase.com/docs/guides/platform/custom-domains#prepare-to-activate-your-domain) เป็นทางเลือก branded provider ที่เป็น paid add-on บน paid plan ต้องเตรียม OAuth callback ก่อน activation; [อัตราปัจจุบัน](https://supabase.com/docs/guides/platform/manage-your-usage/custom-domains) $0.0137/ชั่วโมง (ประมาณ $10/เดือน) และไม่อยู่ใต้ Spend Cap ไม่ได้ activate/อัปเกรด และไม่รับรองว่าซื้อแล้ว Gmail จะหยุดเตือน
