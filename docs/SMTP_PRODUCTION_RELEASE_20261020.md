- ก่อน Save: Public DNS มี DKIM `resend._domainkey.mail.korkru.com` (RSA 1024-bit) และ bounce CNAME ทั้ง `send.mail.korkru.com` / `rsend.mail.korkru.com` พร้อม SPF ที่ปลายทาง แต่ DMARC sender/root เป็น NXDOMAIN หลัง Save ตรวจ Google และ Cloudflare DoH เวลา `2026-10-20T06:22:58Z` (13:22:58 น. ไทย) ได้ NOERROR และ TXT `_dmarc.mail.korkru.com` ค่า `v=DMARC1; p=none;` TTL **300 วินาที** ทั้งคู่ ส่วน `_dmarc.korkru.com` ยัง NXDOMAIN ตามขอบเขตเดิม เป็นหลักฐานเห็น record ที่สอง resolver ไม่รับรอง global propagation หรือ `dmarc=pass` ของอีเมล ยังไม่พิสูจน์ว่า DMARC เป็นสาเหตุเดียวของ warning และไม่แทน CNAME/เพิ่ม SPF จากการเดา
- ผู้รับอื่นอาจเห็นคำเตือนได้เช่นกัน แต่ Gmail ตัดสินเป็นรายผู้รับ/ข้อความ จึงไม่รับรองว่าจะเหมือนกันทุกบัญชี Root ไม่กด `Looks safe` หรือเปิด recovery link และไม่ถือว่าปุ่มนั้นเป็นวิธีแก้ให้ทุกคน หลังเตรียม DMARC ต้องตรวจ DNS และอีเมลใหม่ที่เจ้าของควบคุมผู้รับได้: header ต้องแสดง `dmarc=pass`, ไม่มี Gmail danger warning และลิงก์ยัง active/ไม่ถูก tracking แก้ URL หาก warning ยังอยู่ให้ตรวจ sender/link reputation และ template ต่อ ไม่รับรองว่า DMARC เป็นสาเหตุเดียว ยังไม่พร้อมสำหรับผู้ใช้ทุกคนและยังต้องทดสอบ recovery end-to-end
