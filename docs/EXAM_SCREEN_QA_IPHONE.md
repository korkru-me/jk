# รายการตรวจหน้าข้อสอบบน iPhone จริง — เฟส 2B

อัปเดต: 12 กันยายน 2026 · **ยังไม่เริ่ม — รอผู้ใช้ว่าง**

เอกสารนี้เก็บขั้นตอนที่ต้องทำภายหลังเท่านั้น ผู้ใช้ไม่ต้องทดสอบตอนนี้ เฟส 2A ผ่านการตรวจโค้ดและ desktop browser แบบ manual viewport emulation แล้ว แต่ยังไม่ใช่หลักฐานจาก Safari/WebKit หรือแอป SEB บน iPhone จริง

## ก่อนเริ่มภายหลัง

- Agent เปิดห้องทดลอง local และบอกทีละขั้น ผู้ใช้ไม่ต้องจำ URL หรือเปิดหลายอย่างเอง
- ใช้ข้อมูลสมมติเท่านั้น ห้ามใช้ชื่อนักเรียน คำตอบ รูปลายมือ หรือไฟล์ข้อสอบจริง
- จดเฉพาะรุ่น iPhone, รุ่น iOS, รุ่น Safari/SEB, แนวจอ และผล “ผ่าน/ไม่ผ่าน”
- ห้ามส่งหรือ commit password, CK, BEK, token หรือ request hash
- ก่อนเริ่ม Agent ต้องยืนยันว่า route เป็น `/exam-screen-lab` และไม่เชื่อมการส่งคำตอบจริง

## ขั้นตอนที่ Agent จะบอกทีละข้อ

1. เปิดหน้าแบบหนึ่งข้อต่อหน้าในแนวตั้ง ตรวจว่าไม่มีส่วนล้นข้างและปุ่มไม่ถูกบัง
2. พิมพ์คำตอบคณิตศาสตร์ `123` แล้วพิมพ์ข้อความไทยหลายบรรทัด ปิดคีย์บอร์ด และดูว่าคำตอบยังอยู่
3. หมุนเป็นแนวนอนแล้วกลับแนวตั้ง ตรวจว่าไม่เกิดแถบขาว การเลื่อนข้าง หรือปุ่มหาย
4. เปิด **ดูทุกข้อ** กระโดดไปข้อที่ Agent ระบุ แล้วลองโหมดโฟกัสและดูเวลาที่เหลือ
5. จับคู่แบบช่องด้วยการแตะหนึ่งคู่ และแบบโยงเส้นด้วยการแตะหรือสัมผัสจุดเชื่อม
6. เรียงลำดับด้วยปุ่มขึ้น/ลง แล้วลองเลื่อนหน้าผ่านรายการโดยไม่ลากผิด
7. เปิดและปิดเครื่องคิดเลข แป้นคณิตศาสตร์ขั้นสูง และกระดาษทด พร้อมตรวจว่าไม่มีแผงใดบังปุ่มส่ง
8. แนบรูปกระดาษเปล่าและไฟล์สมมติ แล้วนำออก จากนั้นเปิดกล่องยืนยันส่งโดยไม่ส่งข้อมูลจริง

## จุดที่ต้องสังเกตเป็นพิเศษ

- การเปิดกล้องหรือ Files อาจทำให้ browser รายงานว่าออกจากแท็บหรือขาดการติดต่อ ต้องดูผลบน iPhone จริงก่อนแก้ระบบคุมสอบ ห้ามปิดการตรวจจับจากการคาดเดา เพราะอาจทำให้การคุมสอบอ่อนลง
- Browser simulation ไม่พิสูจน์ safe-area, คีย์บอร์ด iOS, file picker, camera picker, WebKit gesture หรือพฤติกรรมใน SEB
- การผ่านห้องทดลองไม่พิสูจน์ autosave, upload, submit, RLS หรือข้อมูลที่ครูเห็น งานเหล่านั้นต้องใช้ staging แยกในเฟส 5–7

เฟส 2 จะเปลี่ยนเป็น “ผ่าน” ได้ต่อเมื่อครบรายการบนเครื่องจริงและบันทึกข้อจำกัดที่พบแล้วเท่านั้น
