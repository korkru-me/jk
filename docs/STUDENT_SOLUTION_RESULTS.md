# ผลคะแนนและลายน้ำเฉลยของนักเรียน

สถานะ 14 ตุลาคม 2026: พัฒนาและตรวจในเครื่อง ผู้ใช้ให้เก็บไว้ปล่อยพร้อมเว็บจริง ไม่มี push/deploy หรือ migration จากงานนี้

## พฤติกรรม

- กรอบคะแนนย่อเป็นแถวเดียวบนจอกว้างและ wrap บนจอแคบ คงคะแนน/การปรับฐานคะแนน เกณฑ์ผ่าน รอตรวจ ซ่อนคะแนน เปิดเฉลย เริ่มรอบใหม่ และ SEB exit ตามเงื่อนไขเดิม
- MCQ แสดงคำตอบที่เลือก รวมตอบถูก ผิด ว่าง และคำตอบข้อความเก่า ใช้ authored index เพื่อหาตำแหน่งในตัวเลือกที่สลับแล้ว และใช้เฉลยที่บันทึกในรอบนั้นก่อน key ปัจจุบัน TF/เรียงลำดับใช้ formatter เดิมเพื่อไม่แสดง raw JSON ประเภทอื่นคง renderer เดิม
- ลบเส้นทางการซ่อมเสริมทั้งหมด ไม่มีการแก้ scoring/รูปแบบ question type/Word
- เฉลยแบบฝึกหัดและข้อสอบในเว็บมีลายน้ำบังคับ: คำนำหน้า+ชื่อสกุล รหัสนักเรียน ชั้น/ห้อง เลขที่ และวันเวลาไทย ข้อมูลมาจาก server หลังตรวจเจ้าของหรือสิทธิ์จัดการงาน ไม่ขึ้นกับ setting ลายน้ำระหว่างทำ
- อ่านข้อมูลเฉพาะเจ้าของผลงาน ไม่มี email/สุขภาพ/ผู้ปกครอง/ข้อมูลเพื่อน หากอ่านตัวตนล้มเหลวไม่ส่งเฉลยที่ไม่มีลายน้ำ ฟิลด์ที่ยังไม่กรอกแสดง “ไม่ระบุ”
- ลายน้ำติด viewport และอยู่เหนือ dialog ไม่รับการคลิก เวลาเริ่มจาก server และเดินต่อด้วย monotonic elapsed time มุมมองครูบอกว่าเป็นผลงานของนักเรียนและเป็นมุมมองผู้สอน

## ขอบเขต PDF ที่ผู้ใช้ยืนยัน

- ลบเฉพาะเมนู Export as PDF และ exportPrint/window.print ในหน้าวิเคราะห์งานของครูตามคำตอบผู้ใช้วันที่ 14 ตุลาคม 2026 หน้าวิเคราะห์และ CSV คงอยู่
- ครูแนบ PDF เป็นเฉลยเดิมที่ คลังโจทย์ → เพิ่ม/แก้ไขโจทย์ → เฉลยวิธีทำ → แนบรูปหรือ PDF นักเรียนเปิดที่ ผลสอบ → ดูเฉลยวิธีทำ → เปิดเฉลย PDF เมื่อผ่าน release gate
- การปรับให้ PDF แนบเปิดในกรอบที่มีลายน้ำพักไว้เป็น local draft นอก commit งานหลักนี้ ผู้ใช้ขอทราบตำแหน่งก่อนตัดสินใจ ไม่มีคำสั่งลบการแนบไฟล์เฉลย
- ลายน้ำเว็บไม่ได้เขียนลงไฟล์ PDF ที่เปิดแยก และไม่ได้ป้องกันการ crop/edit ภาพหรือแก้ DOM จึงไม่ใช่หลักฐานยืนยันผู้เผยแพร่

## ตรวจสอบ

- Browser: ผลคะแนนที่ 320/390/1280/1600px ไม่ล้นแนวนอน กรอบ desktop ประมาณ 181px เลือกตอบถูก/ผิด/ไม่ตอบ/legacy/shuffled แสดงถูกต้อง รวม manual null key
- ลายน้ำยังอยู่เมื่อเลื่อนหน้า/สลับข้อ/เปิดป๊อปอัป และขึ้นในเฉลยแบบฝึกหัดเมื่อ optional overlay ปิด โหมดซ่อนคะแนน/ล็อกเฉลย/โหลดล้มเหลวไม่แสดงคำตอบที่ถูกล็อก
- Axe เฉพาะกรอบคะแนน/ตรวจเฉลย: light ไม่มี violation/incomplete; dark ไม่มี violation แต่มี contrast incomplete หนึ่งรายการ ตรวจภาพเพิ่มเติมแล้ว ไม่ใช่ full-page accessibility certification
- Unit cases ครอบคลุม identity projection, Thai date/leading zero/control chars, shuffled/legacy choices และ server-action ownership/release/failure boundaries ใช้ mocks แทนบัญชีจริง
- ตรวจคอลัมน์ตัวตนที่มีอยู่แล้วใน Staging แบบ zero-row read เท่านั้น ไม่เขียนข้อมูล ไม่เปลี่ยน Production
- ผล TypeScript/token/build/full unit suite บันทึกใน handoff ของ commit ตัวอ่าน PDF draft ยังไม่ถือว่าเสร็จ

ยังไม่ตรวจการส่งคำตอบจริงด้วยบัญชีนักเรียน, native SEB หรืออุปกรณ์สัมผัสจริง งาน attempt-expiry แยก worktree และต้องรวมโดยรักษา closed_at/timeout guards รวมถึง solution_watermark ของงานนี้
