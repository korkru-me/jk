## การตัดสินใจของระยะ 7

1. **ปล่อยเป็นรุ่นทดลองควบคุม** ไม่ประกาศว่า UAT ผ่านครบ เพราะคณะผู้ทรงคุณวุฒิตัวจริงยังไม่เคยใช้ และยังไม่มีใครพิมพ์เอกสารเป็น PDF ไปยื่นจริง
2. **ไม่สร้างฟอร์ม ผู้ทรง หรือคะแนนสมมติค้างไว้ใน production** ข้อมูล UAT ทุกชุดถูกลบเมื่อจบ และยืนยันด้วยการนับแถวว่าทุกตารางของโมดูลนี้เป็นศูนย์
3. **merge เมื่อเจ้าของผลิตภัณฑ์สั่ง ไม่ทำเอง** การ merge เข้า `master` เท่ากับปล่อยขึ้น production · สั่งเมื่อ 14 กันยายน 2569 หลังอ่านเกณฑ์ก่อน merge แล้ว
4. **ยังไม่ทำส่งออก Word (.docx)** ต้องเพิ่ม dependency ใหม่และเขียน layout ของเอกสารซ้ำอีกชุดหนึ่งทั้งชุด เพราะ Word ไม่ได้ใช้ HTML/CSS เดียวกับหน้าพิมพ์ · รอคำตอบว่าคุ้มไหม เมื่อเทียบกับการเปิด PDF แล้วแก้ในโปรแกรมที่ครูถนัด หรือใช้ Excel ที่ทำเสร็จแล้ว
5. **ภาพร่าง 6 รูปหลัง (`phase-ioc-6` ถึง `phase-ioc-11`) ยังอยู่ในสถานะ "รอตรวจ" ในสเปก** แต่หน้าจอจริงถูกสร้างและตรวจตามภาพร่างเหล่านั้นไปแล้ว · ถ้าเจ้าของผลิตภัณฑ์ดูหน้าจอจริงแล้วพอใจ ให้ปรับสถานะในตารางภาพร่างเป็นอนุมัติได้เลย ไม่ต้องย้อนกลับไปดูภาพร่าง
6. **ถ้าต้องย้อนรุ่น** ให้สร้าง revert commit บน `master` แล้วปล่อยผ่านเส้นทางปกติ ห้าม reset, force push หรือแก้ migration ที่ apply แล้ว · ตารางที่ค้างอยู่ในฐานข้อมูลไม่ต้องลบ เพราะไม่มี code เรียก
